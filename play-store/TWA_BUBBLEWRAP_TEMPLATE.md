# Trusted Web Activity / Bubblewrap Template

Google Play requires an Android App Bundle (`.aab`). This web project can be wrapped with Bubblewrap after it is hosted on HTTPS.

## Required Values

- HTTPS app URL, for example `https://your-domain.example/`
- Android package name, for example `com.yourcompany.smartgamessuite`
- App version code and version name
- Signing key or Play App Signing setup
- `.well-known/assetlinks.json` on the hosted domain for Digital Asset Links

## Typical Commands

Install Bubblewrap on your development machine:

```powershell
npm install -g @bubblewrap/cli
```

Initialize the Android wrapper from the hosted manifest:

```powershell
bubblewrap init --manifest https://your-domain.example/manifest.webmanifest
```

Build the Android App Bundle:

```powershell
bubblewrap build
```

Upload the generated `.aab` to Play Console.

## Important

This folder alone cannot be uploaded directly to Play Console. Play Console expects the signed Android App Bundle generated by the wrapper.
