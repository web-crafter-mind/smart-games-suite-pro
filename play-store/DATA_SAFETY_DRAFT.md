# Data Safety Draft

Use this as a Play Console guide. Confirm every answer yourself before submission.

## Data Collection

Recommended answer: The app does not collect or share user data with a server.

Reason: Gameplay names, scores, settings, achievements, and leaderboard entries are stored locally on the device using browser/app storage. The app does not include third-party advertising, analytics, login, or remote database code.

## Data Sharing

Recommended answer: No data is shared with third parties.

## Security Practices

Recommended answer: Data is not transmitted off device by the app. If published as a Trusted Web Activity, host the web app over HTTPS.

## Data Types Present Locally

- Player name entered by the user
- Local scores and leaderboards
- Audio settings
- Power Hub progress, XP, streaks, achievements, and daily challenge status

## Deletion

Users can clear data by using in-app leaderboard reset where available, resetting Power Hub progress, or clearing app storage from Android settings.

## Notes For Play Review

If you add ads, analytics, cloud saves, crash reporting, sign-in, payments, or online multiplayer later, update this Data Safety form before publishing an update.
